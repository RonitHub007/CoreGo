// Understanding the map internals in golang 

Like Everyother language Map in Golang was introduced when it was getting tough for devs to handle sequential data 
when one associates with other .

Syntax => map[keyType]valueType

As with other Data Structures Map if just decalred and have no key value returns nil

Example : nilMap := map[string]int   => Accesing the nilMap cause panic(error) in golang
